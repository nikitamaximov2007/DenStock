# Ошибка HTTPS и канонический адрес

Если браузер показывает `ERR_SSL_PROTOCOL_ERROR` при открытии DenisStock по
голому IP, сначала не повторяйте проведённую операцию. Откройте список
соответствующих документов и «Склад» - «История», чтобы убедиться, что продажа
или другое действие не было выполнено до ошибки и не появилось дважды.

Затем откройте DenisStock по каноническому адресу, который передан ИИ в
безопасном контексте. ИИ не должен придумывать домен, просить сертификат,
показывать внутреннюю сетевую конфигурацию или советовать отключить проверку
TLS. Если канонический адрес тоже не открывается, можно создать ручное
обращение с точным текстом браузерной ошибки и безопасной диагностикой.
