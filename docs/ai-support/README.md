# База знаний ИИ-поддержки DenisStock

Эти документы содержат только пользовательские факты, подтверждённые текущими
URL, views, forms, services, templates, тестами и руководством DenisStock. Они
используются локальным детерминированным retrieval в `apps.ai_support.knowledge`.

Правила обновления:

1. При изменении пользовательского сценария сначала сверить URL, permission,
   подписи полей и кнопок, затем момент складской мутации в service.
2. Не описывать модель, route или внутренний endpoint как пользовательскую кнопку.
3. Не смешивать первичный ввод ячейки со сверкой существующего остатка.
4. Не смешивать обычную продажу с продажей из «Быстрых действий».
5. Если факт не подтверждён кодом или тестом, написать
   `Требует подтверждения владельцем продукта`.
6. Не помещать сюда пароли, токены, cookies, персональные данные клиентов,
   production-настройки или содержимое базы данных.

ИИ использует эти файлы как справочные данные, но остаётся read-only: документы
не дают ему права выполнять POST-запросы, менять остатки или запускать команды.
