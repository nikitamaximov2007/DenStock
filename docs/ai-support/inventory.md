# Инвентаризация и пересчёт ячейки

Путь: «Склад» - «Инвентаризация». Здесь два разных режима. Сначала нужно
понять, требуется первичный ввод содержимого пустой в учёте ячейки или сверка
уже существующего остатка.

## Инвентаризация ячейки: первичный ввод сканированием

Доступ: Администратор, Руководитель, Кладовщик.

1. Откройте вкладку «Инвентаризация ячейки» и нажмите «Новый пересчёт».
2. Заполните «Стеллаж (S)», «Уровень снизу вверх (L)», «Тип места», при
   необходимости «Номер ящика/коробки», «Ячейка (C)» и «Описание ячейки».
3. Нажмите «Начать пересчёт».
4. На странице ячейки сканируйте точный номер или штрихкод каждой физической
   детали. Кнопка называется «Добавить скан»; сканер обычно отправляет Enter.
5. Проверьте сгруппированные строки и столбец «Количество». Ошибку одного ввода
   можно исправить кнопкой «Отменить последний скан», количество можно изменить,
   неизвестную строку - «Разобрать» или удалить.
6. Нажмите «Завершить пересчёт».
7. На странице завершения нажмите «Создать черновик документа». Поле
   «Запасная цена только для строк без цены (₽)» нужно только когда у строки нет
   цены.
8. Проверьте документ и нажмите «Провести инвентаризацию».

Сканы, ручные правки строк и черновик не меняют склад. Только шаг 8 добавляет
остаток по выбранному адресу и создаёт IC-документ первичного ввода. Этот режим
не сравнивает факт с уже учтённым остатком и при повторном использовании может
добавить количество ещё раз. Незавершённый черновик до «Завершить пересчёт»
можно удалить без изменения склада.

## Сверочные документы: привести существующий остаток к факту

Доступ: роли с правом инвентаризации. Откройте вкладку
«Сверочные документы».

1. Нажмите «Создать инвентаризацию».
2. Выберите «Ячейка (область сверки)», добавьте комментарий и нажмите
   «Создать черновик».
3. В блоке «Добавить лот» выберите подтверждённый количественный лот и нажмите
   «Добавить лот».
4. Для каждой строки введите «Факт» и нажмите «OK».
5. Проверьте «Системное», «Факт» и «Расхождение».
6. Нажмите «Провести инвентаризацию».

До шага 6 остаток не меняется. При проведении система сравнивает факт с живым
количеством, создаёт корректировку только при расхождении и приводит лот к
факту. Провести пустой документ или строку без факта нельзя. Уменьшить остаток
ниже активного резерва нельзя. Отменить можно только черновик; проведённый
документ неизменяем.
