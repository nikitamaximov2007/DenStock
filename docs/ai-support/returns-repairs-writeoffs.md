# Ремонты, возвраты и списания

## Ремонт

Путь: «Ремонты» - «Ремонты». Доступ: Администратор, Руководитель,
Кладовщик, Продавец/Мастер.

Создайте ремонтный заказ, заполните данные клиента и техники, добавьте доступные
позиции и проверьте цену детали для клиента. По умолчанию берётся рекомендуемая
цена, но в черновике её можно изменить. Нажмите «Провести (выдать в ремонт)».
До проведения это черновик. Цена детали и себестоимость фиксируются отдельно;
стоимость работ DenisStock не хранит.
Проведение уменьшает склад и создаёт движения выдачи. Отменить можно только
черновик. Для физического возврата из проведённого заказа пользователь с правом
возвратов нажимает «Оформить возврат».

## Возврат на склад

Возврат создаётся только из карточки проведённой продажи или ремонта кнопкой
«Оформить возврат». Затем:

1. Создайте черновик возврата.
2. Для нужной исходной строки выберите «Ячейка возврата», «Состояние» и
   количество, затем нажмите «Вернуть».
3. Проверьте строки и нажмите «Провести возврат».

Только проведение возвращает физический остаток и создаёт движение возврата.
Для продажи оно не меняет исходную выручку. Проведённый возврат можно отменить
только пока возвращённый остаток остаётся доступен в той же ячейке и не
использован последующими операциями; требуется причина, а отмена создаёт
компенсирующие складские движения.

## Списание

Доступ: Администратор, Руководитель, Кладовщик. Внутренний путь из раздела
«Склад» ведёт на список «Списания».

1. Нажмите «Создать списание».
2. Выберите причину, добавьте комментарий и создайте черновик.
3. Добавьте доступный или карантинный экземпляр либо количественный лот.
4. Нажмите «Провести (списать)».

Только проведение уменьшает остаток и создаёт движение списания. Пустой
документ провести нельзя. Кнопка «Отменить документ» доступна только для
черновика; проведённое списание не отменяется прямым редактированием.
