# Поиск и карточка детали

## Найти деталь и ячейку

Доступ: все рабочие роли. Путь: «Поиск».

1. Введите не менее двух символов в универсальное поле поиска или отсканируйте
   код, когда поле находится в режиме сканера.
2. Нажмите «Найти» или отправьте код сканером.
3. В результате проверьте точный артикул, название, производителя, цену,
   «Физически», «Зарезервировано», «Доступно» и строки по ячейкам.
4. Для подробностей откройте карточку детали. Пользователи с правом просмотра
   склада также видят ссылки на конкретные складские записи.

Приоритет общего resolver: точный номер, штрихкод, дополнительный номер,
название. BRP replacement и Polaris superseded показываются как справочные
связанные результаты и не считаются фактическим складским остатком другого
артикула.

## Общий сканер

Старый read-only URL «Сканер» безопасно переводит код в единый «Поиск». Сам
общий сканер ничего не принимает, не перемещает и не списывает. Для операций
нужно использовать специализированные экраны «Приёмка сканером»,
«Перемещение», «Инвентаризация ячейки» или «Быстрые действия».

## Добавить деталь, которой нет в каталоге

Доступ: право управления каталогом. Путь: «Добавить деталь» на главной, в
списке деталей или из черновика поступления.

1. Заполните «Название». Это единственное обязательное поле.
2. Заполните «Артикул», если номер известен. С ним деталь находится по номеру,
   без него - только по названию.
3. Заполните «Рекомендуемая цена, ₽», если она известна. Это цена для клиента,
   а не себестоимость: себестоимость появится сама при первой приёмке.
4. Нажмите «Добавить деталь».

Если деталь с таким артикулом уже заведена, экран показывает список найденного
и предлагает открыть её. Это предупреждение, а не отказ: одинаковые номера у
разных производителей встречаются, поэтому кнопка «Всё равно создать» остаётся
доступной. Одинаковые номера системой не запрещены.

Остальные поля карточки - производитель, категория, минимальный остаток -
заполняются потом, в обычном редактировании детали. Категория подставляется
сама: «Добавлено вручную». Единица - «Штука», режим учёта - количественный.

Созданная карточка сразу находится поиском и доступна в поступлении, продаже и
ремонте. Остаток на складе она не создаёт: он появляется только после приёмки.

## Карточка детали

Карточка содержит основные свойства, точные номера, заводские штрихкоды,
совместимость и ссылки на остатки. Пользователь с правом управления каталогом
может нажать «Добавить номер», «Добавить штрихкод» или
«Добавить совместимость». Создание карточки детали само по себе не создаёт
остаток.

Если скан не распознан, администратор или руководитель может открыть внутренний
экран «Нераспознанные сканы», затем добавить реальный штрихкод в правильную
карточку детали. Нельзя привязывать неизвестный код наугад.
