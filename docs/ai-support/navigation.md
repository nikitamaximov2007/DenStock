# Навигация

В основном левом меню отдельно расположены «Главная», «Поиск» и
«ИИ-поддержка». Раскрывающиеся группы показываются только при наличии доступных
пользователю функций.

Основные группы и подпункты:

- «Склад»: «Остатки», «Ячейки», «Поступление», «Перемещение»,
  «Инвентаризация», «Быстрые действия», «История».
- «Продажи»: «Клиенты», «Продажи», «Резервы», «Возвраты покупателей».
- «Ремонты»: «Ремонты», «Возвраты из ремонта».
- «Отчёты»: «Сводка», «Продажи по клиентам», «Ремонты по клиентам»,
  «Складские действия / Таможня», «Статистика».
- «Настройки»: «Цены», «Пользователи», «Бэкапы» в зависимости от прав.

Внутренние вкладки:

- В «Поступлении» доступны «Поступления», «Партии поставок» и
  «Приёмка сканером» согласно правам.
- В «Инвентаризации» есть два разных режима: «Инвентаризация ячейки» для
  первичного ввода сканированием и «Сверочные документы» для сравнения
  существующего количественного остатка с фактом.
- «Экземпляры» и «Лоты» открываются из «Остатков», карточек деталей, ячеек и
  партий, но не являются самостоятельными пунктами основного sidebar.
- «Списания», «Справочники» и «Инструменты / Нераспознанные» доступны из
  связанных внутренних экранов при наличии прав, но не являются постоянными
  подпунктами основного sidebar.

Если раздел отсутствует, сначала нужно проверить роль пользователя. Скрытый
пункт меню не отменяет серверную проверку permission.
