# Ключи восстановления: чек-лист владельца

Цель: восстановить DenisStock при одновременной потере сервера, Yandex и
Mac. Секретов в документе нет.

## Что из чего восстанавливается

| Компонент | Секрет | Где хранить | Без него |
| --- | --- | --- | --- |
| Парольная фраза ключа восстановления | да | Apple Passwords И бумага в запечатанном конверте в другом здании | ничего не расшифровать |
| `recovery-identity.age` (ключ, сам зашифрован фразой) | условно | Mac, внешний SSD, второй носитель | ничего не расшифровать |
| Публичный ключ подписи `production-manifest-ed25519-public.pem` | нет | Mac, SSD, README репозитория копий, распечатка отпечатка SHA-256 | нечем проверить подлинность копии |
| Зашифрованные копии (`*.signed-backup.tar.age`) | нет (зашифрованы) | Yandex, Mac, SSD, GitHub Releases (после включения) | нет данных |
| Зашифрованные секреты (`production-secrets-*.tar.age`) | нет (зашифрованы) | Mac, SSD | можно создать заново (`--fresh-secrets`), токены ботов получить заново |
| Исходный код | нет | GitHub `DenStock`, бандл в комплекте | бандл из комплекта |

Правило: фраза и ключ никогда не лежат вместе с копиями в одном месте без
защиты. Ключ без фразы бесполезен, фраза без ключа тоже: храните их порознь.

## Сделать один раз

1. Внешний SSD с шифрованием APFS (пароль, отличный от фразы ключа):
   скопировать `~/DenisStock-Recovery`, `~/DenisStock-Recovery-Updates`,
   `~/Desktop/DenisStock-Emergency-Transfer/production-manifest-ed25519-public.pem`.
   Проверить копию: `shasum -a 256` исходных и скопированных файлов.
   Хранить SSD не рядом с Mac.
2. Бумага: парольная фраза ключа восстановления и пароль SSD, в запечатанном
   конверте, в другом месте (не там, где SSD).
3. Отпечаток публичного ключа подписи: `shasum -a 256 production-manifest-ed25519-public.pem`,
   записать на ту же бумагу.
4. После включения GitHub-копий: положить публичный ключ подписи в README
   приватного репозитория копий.

## Каждый месяц

- Обновить SSD свежей зашифрованной копией (Mac или GitHub `fetch`).

## Каждый квартал

- Учебное восстановление на Mac: `scripts/dr/morning_real_drill.sh`
  (ветка `claude/offline-full-service-restore`), фразу вводит владелец.
  Записать время и результат. Это единственная проверка, что фраза,
  ключ и копии действительно работают вместе.
