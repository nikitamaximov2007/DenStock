# Выпуск /in-stock/ для публичного каталога: план (не выполнялся)

Ветка `claude/seo-in-stock-release` (база production web `f7b8086`): перенос
`claude/seo-indexation-audit` (`4bc1e68`) и исправления по аудиту Codex.

## Что исправлено по аудиту

1. Стоимость: на production один `live_stock_rows()` стоит 0.8-1.1 с (912
   строк остатка, 2026-10-12), а список и sitemap вызывали его на каждый
   анонимный запрос. Теперь набор «в наличии» кэшируется на 5 минут в
   процессе (`LocMemCache` у `catalog-web`). Синтетика PG16, 2 500 деталей:
   холодная первая страница 0.32 с, страница 40 из кэша 0.023 с, sitemap из
   кэша 0.066 с. Карточка детали показывает живой остаток; список может
   отставать до 5 минут.
2. `lastmod` в `/sitemaps/in-stock.xml`: последнее из `updated_at` карточки,
   её партий и экземпляров (поступление и продажа меняют их, а не карточку).
   Движения склада публичной роли недоступны, партии и экземпляры доступны.
3. «Три клика» было неверно для поздних страниц (стрелки «назад/вперёд», на
   production 18 страниц). Теперь каждая страница ссылается на все страницы
   (до 100): главная, любая страница списка, деталь.

## Что выпуск затрагивает

- Сервис: `catalog-web` (профиль `public-catalog`). `web` для этой функции не
  нужен.
- `catalog-web` сейчас работает на коде около 2026-09-28 (`33be166` по
  хешам файлов, метки коммита у контейнера нет). Пересборка из этой ветки
  принесёт в публичный каталог и всё, что накопилось с тех пор в общем коде,
  в том числе изменённый `apps/catalog/search.py` (поиск по названию) и текст
  `about.html`. Это часть квалификации выпуска, а не только `/in-stock/`.
- Миграций нет; `0028` уже применена на production.

## Порядок

1. PRE-бэкап штатной службой и проверка (подпись, дамп, чтение назад).
2. Тег отката: `docker tag denstock-catalog-web:latest denstock-catalog-web:rollback-<дата>`.
3. `git checkout --detach <SHA>` (общий checkout с web; `DENSTOCK_APP_COMMIT`
   для web не меняется, если web не пересобирается).
4. `docker compose --profile public-catalog build catalog-web`,
   `docker compose --profile public-catalog up -d --no-deps --wait catalog-web`.
5. Проверка: `/in-stock/` 200, страницы и ссылки на все страницы, `?page=1`
   301, лишняя страница 404, `/sitemap.xml` первым ссылается на
   `/sitemaps/in-stock.xml`, `robots.txt`, поиск по артикулу и названию,
   карточки деталей, корзина/заявка; ошибок в логах `catalog-web` нет.
6. POST-бэкап.

Внимание: checkout общий для `web` и `catalog-web`; следующий выпуск `web`
должен строиться на линии, содержащей эту ветку, иначе `catalog-web` при
следующей пересборке потеряет `/in-stock/`.

## Откат

`docker tag denstock-catalog-web:rollback-<дата> denstock-catalog-web:latest`,
`up -d --no-deps --no-build catalog-web`. Данные не затрагиваются.

## Замечание по безопасности (не меняется этим выпуском)

Роль `denstock_public` может читать колонки себестоимости
(`landed_cost_rub`) в партиях и экземплярах. Приложение их не показывает,
но права шире необходимого; сужение прав это изменение БД production и
требует отдельного решения.
