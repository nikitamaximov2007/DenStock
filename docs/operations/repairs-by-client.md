# Ремонты по клиентам

## Назначение

Отчёт находится в «Отчёты» -> «Ремонты по клиентам» и отвечает на три вопроса:

1. Каким клиентам выдавались детали в ремонт в выбранный период.
2. Какие детали и в каком количестве ушли конкретному клиенту.
3. Из каких проведённых ремонтных заказов сложилась строка детали.

Отчёт полностью read-only. Он не меняет заказы, остатки, движения или цены.

## Денежная семантика: выручки по ремонтам НЕТ

Это главное отличие от отчёта «Продажи по клиентам», и его нельзя обходить
молча.

Ремонтный заказ фиксирует, КУДА (на какую технику) и ЗАЧЕМ ушли детали, и
замораживает их себестоимость. Цены работ, оплаты, чека и прибыли в системе
нет: у модели `RepairOrder` нет ни одного поля клиентской суммы, есть только
`cost_total` со смыслом «себестоимость выданного». Поэтому:

- в отчёте нет и не будет колонки выручки по ремонтам;
- колонка «Себестоимость выданного (₽)» это ЗАКУПОЧНАЯ стоимость деталей, а не
  сумма, выставленная клиенту, и называть её выручкой нельзя;
- эта колонка видна только ролям с правом на закупочные цены
  (`can_view_purchase_cost`), как и в остальных отчётах;
- сортировка клиентов идёт по количеству выданных единиц, а не по деньгам:
  количество видно всем, кому открыт раздел отчётов.

Если в будущем появится клиентская сумма ремонта (цена работ, счёт, оплата),
это будет отдельное поле и отдельное решение. До тех пор складывать продажи с
себестоимостью ремонта нельзя: это разные величины.

## Источник данных

В отчёт входят только заказы со статусом `COMPLETED`. Период применяется к
`RepairOrder.completed_at`, включая обе выбранные даты целиком. Черновики и
отменённые заказы не учитываются.

Количество читается из `RepairIssueLine.quantity`, себестоимость из
`RepairIssueLine.total_cost_rub` и `unit_cost_rub`. Это значения, замороженные
в момент проведения заказа; последующие изменения landed cost исторический
отчёт не меняют.

Имя клиента берётся из `RepairOrder.customer_name` и очищается от пробелов по
краям. Пустые имена объединяются в отдельную строку «Без клиента»: создать
заказ без клиента через интерфейс нельзя, такая строка возможна только у
унаследованных записей.

Название и канонический артикул детали показываются из текущей карточки той же
детали, как и в отчёте по продажам. Количественные и стоимостные значения при
этом остаются историческими.

## Экраны

1. «Ремонты по клиентам»: клиент, число ремонтов, число уникальных артикулов,
   выданные единицы, себестоимость выданного, дата последнего ремонта.
2. Карточка клиента: те же величины в разрезе деталей.
3. «Выдачи в ремонт»: отдельные строки с датой, номером заказа, техникой,
   количеством и замороженной себестоимостью. Номер заказа ведёт в исходный
   документ.
