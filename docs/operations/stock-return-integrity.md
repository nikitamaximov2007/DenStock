# Целостность проведённых возвратов

Проведённый `StockReturn` является складским документом с эффектом ровно один
раз. Его статус и складские строки нельзя менять через Django admin или ORM.
Штатная отмена, если безопасна, делает отдельное компенсирующее движение.

При расследовании подозрения на двойной возврат сравните в транзакции
`READ ONLY` количество и сумму строк `returns_stockreturnline` с движениями
`inventory_stockmovement` типа `return_lot`/`return_item`, где
`document_type = 'stock_return'` и `document_id` равен ID возврата. Движений
больше строк или сумма движений больше суммы строк - повод для отдельного
разбора, но не для автоматического исправления. Также проверьте черновики,
уже имеющие такие движения. Не переписывайте журнал и не меняйте остатки
вручную.

При подготовке этого hotfix аудит production только на чтение обнаружил
`RET-000011`: одна строка на 1 и два движения `RETURN_LOT` по 1 в разные лоты.
`RET-000003`: черновик без строк, но с одним старым `RETURN_LOT` на 1.
Оба документа оставлены без изменений и требуют отдельного решения владельца.
