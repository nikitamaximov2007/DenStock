# Матрица отказов DenisStock

Состояние на 2026-10-13. Колонки: ОБНАРУЖИТСЯ (кто и как узнает), ВОССТАНОВИМО
(из чего), МАКС. ПОТЕРЯ ДАННЫХ, ДЕЙСТВИЕ ВЛАДЕЛЬЦА, ДОКАЗАНО (проверено
прогоном) или ПРЕДПОЛОЖЕНО (вывод без прогона).

Обозначения копий: Y = ночная копия в Yandex; M = зашифрованный комплект на
Mac владельца; I = независимый провайдер (подготовлен, НЕ развернут); D =
внешний диск (НЕ сделан).

## Открытые риски по важности

1. Нет второго физического носителя (D) и независимого провайдера (I) в
   эксплуатации: при потере Mac вместе с VPS и Yandex данные теряются.
2. У парольной фразы один способ хранения.
3. Комплект M обновляется вручную: потеря данных растет каждый день.
4. Полный сервис на реальных данных не запускался: ждет фразы владельца
   (`scripts/dr/morning_real_drill.sh`).
