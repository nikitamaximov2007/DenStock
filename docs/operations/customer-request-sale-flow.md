# Продажа по заявке клиента

Заявка из публичного каталога остаётся историческим снимком: имя, телефон,
позиции и `price_seen` не переписываются текущими данными каталога.

Оператор сначала нажимает «Взять в работу». Это меняет статус и сохраняет
оператора, но не создаёт продажу, резерв или складское движение.

Затем на странице заявки доступно «Оформить продажу по заявке». DenisStock
сравнивает нормализованный телефон заявки с карточками клиентов. При одном
совпадении карточка выбирается автоматически; имя карточки не меняется. При
нуле совпадений оператор явно выбирает «Создать клиента из заявки», а при
нескольких совпадениях выбирает карточку вручную. Автоматического объединения
карточек нет.

Открытие действия создаёт обычный черновик продажи и заполняет его текущими
позициями, количествами и доступным складским источником. Черновик не меняет
остаток. Перед «Провести продажу» система заново проверяет состав заявки,
актуальную клиентскую цену и доступность источников. Только после успешной
проверки существующий атомарный сервис продажи создаёт снимки строк и
складские движения. Заявка получает ссылку на единственную продажу и статус
«Выполнена».

Если проведению не хватает таможенных данных, в карточке заявки и в
подготовленной продаже показываются конкретные незаполненные позиции и кнопка
«Заполнить данные». Она открывает общий customs workflow для этой заявки:
заполняются только отсутствующие вес брутто, вес нетто или область применения.
После сохранения оператор возвращается в ту же подготовленную продажу. Данные
записываются в единственную текущую карточку `PartCustomsInfo`, продажа остаётся
черновиком, а остаток не меняется. Проведение по-прежнему выполняется только
отдельной кнопкой «Провести продажу».

Связь заявки с продажей уникальна на уровне базы данных, поэтому повторная
отправка кнопки проведения возвращает ту же продажу и не создаёт второе
движение. Ошибка проверки откатывает проведение целиком.

Для сверки исторических данных доступна read-only команда:

```text
python manage.py audit_customer_request_customer_matches
```

Она выводит только количества и редактированные идентификаторы дубликатов,
не изменяя клиентов, заявки или продажи.
