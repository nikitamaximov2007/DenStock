# R10: инвентарь исходников

В путях `{EM}` обозначает символ U+2014 в имени файла; в JSON символ
хранится в стандартном Unicode-экранировании.

Снимок 18.11.2026, `ffprobe`; пути относительно `~/Desktop/Рилсы` на Mac.
Для публичного Git абсолютный путь пользователя намеренно не записывается.
Длительность в секундах, FPS: средняя частота в виде дроби (записи экрана
могут быть переменной частоты); размеры хранятся как в потоке, без учёта
метаданных поворота. Назначение старых и новых материалов различается ниже.
Данные кадров, переписок и конфиденциальные сведения не копируются в Git.

служебных `.agents`, `.claude` и созданных кадров аудита. Перечислены все
153 найденных MOV/MP4/M4A/WAV/MP3 вне этих каталогов. Прочие документы и
проекты перечислены после таблицы. TO VERIFY = содержимое или дубль ещё не
просмотрены полностью; инвентарь не доказывает использование в новом монтаже.
