# MAX для заявок клиентов

MAX подключён на уровне домена, без выдумывания внешних API. Он использует тот
же защищённый контур, что Telegram: случайный одноразовый токен, хранение
только SHA-256, ограниченный срок, отзыв и минимальный remote chat ID после
явного старта пользователя.

`MaxProvider` и `handle_max_start` являются тестируемой границей для будущего
официального transport adapter. DenisStock сохраняет заявку и её статус у
себя, а не переносит бизнес-истину в мессенджер.

В этой версии намеренно отсутствуют URL, webhook и credentials MAX: без
официально проверенной документации и выданных учётных данных их нельзя
безопасно заявлять. Live acceptance, HTTPS endpoint и реальная отправка
подтверждения остаются внешней launch-задачей.
