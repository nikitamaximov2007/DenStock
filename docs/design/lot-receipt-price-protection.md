# Защита цены по приёмке

Цена по умолчанию для продаваемого лота или серийного экземпляра равна
`MAX(текущая каноническая цена детали, снимок цены при приёмке)`.

Снимок хранится отдельно на каждом `StockLot` и `PartItem`. Поэтому старый
лот, принятый при цене 22 534 ₽, не повышает цену нового лота, принятого при
18 000 ₽. После исчерпания старого лота применяется снимок нового лота.

Снимок создаётся только при новой приёмке и никогда не обновляется импортом,
курсом, наценкой, перемещением или отменой продажи. Исторические остатки не
получают выдуманный снимок: `NULL` сохраняет прежнее поведение текущей цены.

Ручная цена оператора и уже проведённые `SaleLine` не изменяются.
