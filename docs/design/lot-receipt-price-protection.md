# Защита цены по приёмке

Для нового фактически принятого `StockLot` или `PartItem` сохраняется
каноническая цена клиента на момент проведения поступления.

При продаже, выдаче в ремонт и продаже из резерва default для уже выбранного
источника равен `MAX(current canonical price, receipt snapshot)`. Правило не
использует себестоимость и не хранит максимальную цену за всю историю детали.
Поэтому законченный старый лот не влияет на цену новой партии.

Снимок принадлежит самому лоту или экземпляру. Он создаётся только при новом
проведении поступления. У существующего до миграции склада поле остаётся
`NULL`: цену нельзя достоверно восстановить, поэтому default остаётся текущей
канонической ценой.

Ручная цена документа и уже сохранённые `SaleLine`/`RepairIssueLine` не
переписываются. Возврат возвращает товар в тот же источник и не создаёт новый
снимок.

Read-only команда `audit_below_cost_customer_documents --csv <path>` выводит
проведённые продажи и ремонтные выдачи, где сумма для клиента ниже замороженной
себестоимости. В отчёте есть источник, снимок, текущая цена и вероятная
классификация A-G; historical source без снимка помечается отдельно.
