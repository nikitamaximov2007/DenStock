# Защита цены по приёмке

Для нового фактически принятого `StockLot` или `PartItem` сохраняется
каноническая цена клиента на момент проведения поступления.

При продаже, выдаче в ремонт и продаже из резерва default для уже выбранного
источника равен `MAX(current canonical price, receipt snapshot)`. Правило не
использует себестоимость и не хранит максимальную цену за всю историю детали.
Поэтому законченный старый лот не влияет на цену новой партии.

Снимок принадлежит самому лоту или экземпляру. Он создаётся при новом
проведении поступления. У исторического склада поле остаётся `NULL`, кроме
контролируемой forensic-реконструкции: она допускается только для текущего
`StockLot`, если у него есть единственная проведённая сессия пересчёта,
связанная с exact converted receipt и exact PartType, с положительной ценой
строки `final_customer_price_rub`. Экземпляры PartItem в этот механизм не
входят.

Для исторической реконструкции предназначена явная команда, а не миграция:

```
python manage.py backfill_counting_receipt_customer_price_snapshots --csv /tmp/lot-price-plan.csv
python manage.py backfill_counting_receipt_customer_price_snapshots --apply --csv /tmp/lot-price-applied.csv
```

Первый вызов всегда dry-run. Второй разрешает запись только после проверки
счётчиков. Команда пропускает и отражает в CSV отсутствие доказательств,
неоднозначность, конфликт цен, нулевую или отрицательную цену, цену с
неподдерживаемой точностью и уже заполненный snapshot. Она не изменяет
себестоимость, каноническую цену, остатки, движения или исторические строки
продаж и ремонта; повторный запуск идемпотентен.

Ручная цена документа и уже сохранённые `SaleLine`/`RepairIssueLine` не
переписываются. Возврат возвращает товар в тот же источник и не создаёт новый
снимок.

Read-only команда `audit_below_cost_customer_documents --csv <path>` выводит
проведённые продажи и ремонтные выдачи, где сумма для клиента ниже замороженной
себестоимости. В отчёте есть источник, снимок, текущая цена и вероятная
классификация A-G; historical source без снимка помечается отдельно.
