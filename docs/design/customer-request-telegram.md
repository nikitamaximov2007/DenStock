# Telegram для заявок клиентов

DenisStock остаётся единственным источником истины о заявке, её статусе и
контакте. Telegram хранит только минимальный идентификатор чата, связанный с
конкретной заявкой после явного действия клиента.

## Поток

1. Оператор создаёт одноразовую ссылку для заявки, где выбран Telegram.
2. В базе остаётся SHA-256 токена, срок действия, время использования и
   отзыва. Сырой токен не хранится.
3. Клиент сам открывает официальный deep link `https://t.me/<bot>?start=<token>`
   и запускает бота. До этого бот не может инициировать диалог.
4. Webhook с настроенным секретом принимает только `/start <token>`, связывает
   chat ID и подтверждает связь без передачи телефона, комментария или данных
   заявки в ответе.

Токен не содержит внутренний ID, ограничен по времени, отменяется при выпуске
следующей ссылки и не может использоваться повторно. Отменённая заявка не
принимает новую или старую ссылку.

## Внешняя граница

Реализованы доменная логика, формат официальной Telegram deep link, webhook
secret и mock provider. Реальная настройка Bot API `sendMessage`, домена,
HTTPS webhook и credentials остаётся отдельной launch-проверкой. До неё
production messages не отправляются.
