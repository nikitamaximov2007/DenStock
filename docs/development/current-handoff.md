# Handoff: поиск детали по названию в приёмке и пересчёте

Ветка `codex/finish-part-name-search`, от production SHA
`7f13b16c84f352d44ec631d9e4e6066d472a63d3`, продолжает неизменённую ветку
`claude/part-name-search-receiving-inventory` (`2a0e9af`). Production не
изменялась. Кандидат предназначен для отдельного рассмотрения релиза.

## Реализация

- Приёмка и первичный пересчёт ячейки поддерживают поиск существующей активной
  складской карточки по частичному названию, в том числе по кириллице,
  латинице и фрагментам номера/размера. Оператор выбирает конкретный результат;
  первый результат автоматически не выбирается.
- Точный идентификатор проверяется до поиска по названию. Известный код сохраняет
  прежний поток сканирования; неизвестный code-like ввод сохраняет штатный
  сценарий разбора. При отсутствии активных результатов запрос не превращается
  в складскую позицию.
- Используются ограниченные SQL tiers и максимум 20 вариантов ответа. Активный
  фильтр применяется в SQL до ограничения списка кандидатов.
- Встроенный браузерный скрипт инициализируется при `DOMContentLoaded` и
  `denstock:page-loaded`, защищён от повторной инициализации и устаревших ответов.
- Запись приёмки остаётся отложенной до штатного проведения группы. Выбор в
  пересчёте привязан к точной карточке; фактический остаток меняется только
  штатным финализирующим потоком.

## Проверки

- Профильный набор на SQLite и PostgreSQL 16.15 с `LC_COLLATE=C` / `LC_CTYPE=C`.
- Полный SQLite suite сравнен с чистой базой `7f13b16`: у кандидата те же
  семь известных несвязанных падений, дополнительных падений нет.
- Node-тесты выбора клавиатурой/указателем, устаревших ответов и повторной
  инициализации.
- Локальный браузер: sidebar partial navigation для приёмки и пересчёта,
  выбор клавиатурой и указателем, back/forward. Проверена узкая ширина 615px
  без горизонтального overflow; эмуляция 390px отдельно недоступна.
- Синтетический benchmark PostgreSQL с 126,114 импортированными карточками:
  20 результатов, 32 запроса для пяти прогонов, медиана 46.26 мс, максимум
  54.22 мс на локальном стенде. Эти показатели не являются production SLO.
- Базовые ограничения существующего каталожного поиска: три теста общего
  набора (лимит запросов и два кириллических fuzzy typo случая) падают также
  на baseline. Частичный поиск имён, требуемый этой задачей, проходит.
- Полный PG16 suite на baseline `7f13b16` завершился с 16 failures; кандидат
  завершился с теми же 16 failures плюс один failure нового теста гонки выбора
  карточки. Тест гонки затем прошёл шесть отдельных запусков. До отдельного
  успешного полного прогона или объяснения нестабильности P0 не квалифицирован
  для релиза.
